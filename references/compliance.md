# 输出内容合规红线

来源：麦当劳《程序员创意开发大赛活动规则》"内容合规"条款 + 参赛声明。
报告生成、README、社交分享文案都必须遵守。

## 禁止出现

- 违反法律法规、损害国家尊严与利益、妨碍社会安定的内容
- 政治敏感内容
- 宣扬淫秽色情、赌博、迷信、恐怖、暴力，以及民族/种族/宗教/性别歧视
- **宣扬不健康饮食方式、奢靡浪费、拜金主义、娱乐至上、畸形审美**
- 侮辱、诋毁、讽刺、贬低麦当劳品牌、产品及形象
- **将麦当劳品牌或产品与其他品牌、产品进行对比**
- 侵害第三方知识产权、隐私权、商业秘密
- 恶意脚本、钓鱼链接、违规外链

## 本项目对应的具体约束

| 风险点 | 处理方式 |
|---|---|
| 热量/营养数字易被读成"不健康" | 一律标注"按公开营养信息估算的参考值，不构成健康或营养建议" |
| "深夜订单"易被读成不良作息 | 表述为中性趣味的"深夜编译指数"，不作评价 |
| 消费金额易被读成"浪费" | 只陈述金额与节省额，不评价消费行为 |
| 与其他餐饮品牌对比 | 全文禁止出现任何对比 |
| 真实 Token / 个人信息 | 配置文件只用环境变量占位符，原始响应默认不入库（在 .gitignore 中排除 data/） |
| 抽奖类 tool | `draw-lottery` 会真实消耗积分，本项目的默认流程不调用 |

## 措辞替换表

|---|---|

| 比 XX 品牌便宜 | 券后价 ¥X |

只能通过公开分享作品本身获得 Star。
